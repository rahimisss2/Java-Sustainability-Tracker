This folder contains 2 simple coding projects that I made 
to solve real-world sustainability problems.

-----------------------------------------------------------
📊 1. Electricity Bill Calculator (ElectricCalc.java)
-----------------------------------------------------------
- Purpose: Helps people estimate their monthly electricity bill 
  for any home appliance.
- Input  : The user enters the hardware power (Watt) and daily hours.
- Output : Displays the total kWh used and the estimated cost.

-----------------------------------------------------------
🍏 2. Food Waste Tracker (FoodWasteTracker.java)
-----------------------------------------------------------
- Purpose: Helps cafeterias monitor how much food they waste 
  to prevent losing money.
- Input  : The user enters the food type and weight (kg).
- Output : Displays the estimated money lost from the wasted food.

-----------------------------------------------------------
🚀 HOW TO RUN THE CODE IN VS CODE:
-----------------------------------------------------------
Open your terminal in VS Code and type these commands:

For the Electricity Calculator:
> javac ElectricCalc.java
> java ElectricCalc

For the Food Waste Tracker:
> javac FoodWasteTracker.java
> java FoodWasteTracker
